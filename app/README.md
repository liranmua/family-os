# Family OS — שלב 1: Prototype PWA מקומי

אפליקציית שלד שרצה **לגמרי בצד הלקוח**. אין ענן, אין חשבונות גוגל, אין Firebase, אין
Push-שרת. כל הנתונים נשמרים ב-`IndexedDB` במכשיר של המשתמש בלבד.

מתפתח מ-`../family_hub_dashboard.html` (הסקיצה המאושרת) — ראו `../CLAUDE.md` ו-
`../Family_OS_Phase1_Handoff.md` להקשר מלא.

## הרצה מקומית

```
node scripts/serve.mjs 4173
```
ואז לפתוח http://localhost:4173 . (צריך שרת — `file://` לא ירשום Service Worker.)
שרת סטטי מינימלי, בלי תלויות npm.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד + טאבים |
| `css/styles.css` | עיצוב (מתוך הדשבורד) |
| `js/constants.js` | קטגוריות, אנשים, מפות תצוגה, כלי עזר |
| `js/db.js` | עטיפת IndexedDB (7 stores) |
| `js/state.js` | state בזיכרון + כתיבה-דרך ל-DB + זריעה/איפוס |
| `js/seed.js` | נתוני דוגמה ראשוניים |
| `js/render.js` | פונקציות render (קוראות מ-state) |
| `js/forms.js` | מודאל פירוט + טופסי הוספה/עריכה/מחיקה |
| `js/notifications.js` | התראות פנימיות — toast בתוך הדף, 3 טריגרים, סריקה כל 60ש' (בלי הרשאת דפדפן) |
| `js/app.js` | bootstrap: רישום SW, טעינה, חיווט |
| `sw.js` | app-shell cache ל-offline + `notificationclick` |
| `manifest.webmanifest` | מטא-דאטה ל-PWA (dir=rtl, standalone) |
| `icons/` | אייקונים (נוצרים ע"י `../scripts/make-icons.mjs`) |

## מה חי / מה עדיין לא

- **חי ומחובר** (נשמר ונטען מ-IndexedDB): כל ה-CRUD — משימות (כולל תתי-משימות), שגרות +
  סימון "בוצע היום", פרויקטים, רשימת קניות. KPIs. פילטר תחום. איפוס הכל.
- **חי, בלי הרשאה נדרשת**: התראות פנימיות (toast בתוך הדף) — פעילות רק כשהאפליקציה פתוחה
  בפועל (טאב פתוח/ברקע), לא כשהיא סגורה. שלושה טריגרים: בלוק שבועי מתקרב, משימה עם יעד
  מתקרב, פריט קניות שנוסף ממכשיר אחר. **אין** עדיין Push מהשרת (סבב נפרד, ראו CLAUDE.md).
- **מוקאפ בלבד / לא במימוש**: לוג העדכונים (`updatesLog`) מוצג אבל אין עדיין טופס להוספת
  רשומה. תצוגת פיננסים מופשטת — עדיין לא נבנתה (רק KPI כללי).

## בדיקה ידנית של התראות

1. להוסיף משימה עם תאריך = היום ושעה בעוד פחות משעה (או בלי שעה, אחרי 08:00).
2. להשאיר את הטאב פתוח (או ברקע) — עד דקה אמורה להופיע toast בתחתית העמוד.
3. לרענן — אותה התראה לא חוזרת (מפתח נשמר ב-`meta.notifFiredKeys`).
   לבדיקה מהירה בלי לחכות: `window.__familyosNotifyTest()` ב-console.
